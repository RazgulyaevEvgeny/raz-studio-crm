# Учёт студии брендирования Разгуляев

Веб-приложение для сотрудников студии: заказы и ведомость, календарь с задачами, поручения от начальства, расходы офиса, закупка расходников, проекты и прайс.

Сайт работает на GitHub Pages, данные хранятся в Firebase (Google) в базе Firestore на бесплатном тарифе Spark. Фото сжимаются в браузере примерно до 300 КБ и тоже хранятся в Firestore, поэтому Storage и привязка карты не нужны. Можно прикреплять фото и PDF до 700 КБ, видео не поддерживается. Сотрудники входят по почте и паролю.

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | Сама страница учёта |
| `firebase-bridge.js` | Связка страницы с Firebase и экран входа |
| `firebase-config.js` | Настройки вашего проекта Firebase (заполнить один раз) |
| `firestore.rules` | Правила доступа к базе: только вошедшие сотрудники |
| `storage.rules` | Правила для Storage, если когда-нибудь включите его (сейчас не используется) |

## Настройка Firebase (один раз, около 15 минут)

1. Откройте [console.firebase.google.com](https://console.firebase.google.com), нажмите «Создать проект», назовите его, например, `raz-studio`. Google Analytics можно выключить.
2. **Вход сотрудников.** Слева Security → Authentication → Get started → вкладка Sign-in method → Email/Password → включить → Save. Затем вкладка Users → Add user: добавьте почту и пароль для себя и каждого сотрудника.
3. **База.** Databases & Storage → Firestore Database → Create database → редакция Standard, регион `europe-west3 (Frankfurt)` → Start in production mode. Затем вкладка Rules: замените текст содержимым файла `firestore.rules` → Publish.
4. **Настройки для сайта.** Шестерёнка → Project settings → General → внизу «Your apps» → значок `</>` (Web) → назовите приложение → Register. Скопируйте значения из блока `firebaseConfig` в файл `firebase-config.js` вместо надписей «ВСТАВЬТЕ».
5. **Разрешить домен.** Authentication → Settings → Authorized domains → Add domain → `razgulyaevevgeny.github.io`.

## Публикация на GitHub Pages

Репозиторий → Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)` → Save. Через минуту сайт откроется по адресу `https://razgulyaevevgeny.github.io/<имя-репозитория>/`.

## Новые сотрудники

Добавляются в Firebase: Authentication → Users → Add user. Удалить или сменить пароль можно там же.

## Сколько места

Бесплатно Firestore даёт 1 ГБ. Записи заказов почти не занимают места, основное — фото: примерно 3 000 сжатых фото. Если места станет мало, можно включить Storage (нужен тариф Blaze) и перенести файлы туда.

## Маркетинговый отдел

Раздел «Маркетинг» на сайте. Всё работает бесплатно.

| Вкладка | Что там |
|---|---|
| Календарь | События по датам (стратегия, акции и офферы, контент, продажи, рост и цифры). Сверху продажи месяца из учёта, рост к прошлому месяцу, цель месяца с прогрессом и выполнение плана. В клетках дней видны продажи по учёту. |
| Instagram | Профиль и публикации @raz.brandstudio (автоматически через API Instagram или вручную), рубрики, цифры и блок «что есть и чего нет» по услугам |
| Креативы | Дизайнер: ИИ пишет 3 варианта текста и подпись к посту, сайт собирает картинки по фирменным шаблонам (пост, сторис, квадрат) на вашем фото или ИИ-фоне. Скачать PNG, сохранить, поставить в календарь |
| Конкуренты | Карточки конкурентов: что делают, цены, сильные и слабые стороны, ссылки |
| Идеи | Быстрые заметки со статусами: новая, в работе, сделано, отложили |
| Офферы | Готовые предложения: для кого, что входит, цена, срок, статус |
| О студии | Город, контакты, УТП, услуги, клиенты, тон, фирменный стиль, кейсы, цели — это читает вся ИИ-команда |
| ИИ-команда | Маркетолог, SMM-менеджер, аналитик и планёрка всей команды |

ИИ-команда видит прайс, себестоимость, продажи по услугам, цели, календарь, конкурентов, идеи и офферы (без имён и телефонов клиентов) и «Бриф студии». Под каждым ответом есть кнопки «Разложить в календарь», «В идеи», «В офферы». Всё хранится в Firestore, коллекция `marketing`.

Файлы: `marketing.js` — страница раздела, `marketing-creative.js` — шаблоны креативов, `marketing-worker/worker.js` — сервер-посредник с ролями специалистов (тексты ролей правятся там).

### Запуск ИИ-команды (один раз, около 10 минут, бесплатно)

1. **Ключ Gemini.** Откройте [aistudio.google.com](https://aistudio.google.com), войдите в Google-аккаунт → Get API key → Create API key. Карта не нужна.
2. **Сервер.** [dash.cloudflare.com](https://dash.cloudflare.com) → Workers & Pages → Create → Worker → имя `raz-marketing` → Deploy → Edit code: замените код содержимым `marketing-worker/worker.js` → Deploy.
3. **Настройки сервера.** Worker → Settings → Variables and Secrets:
   - `GEMINI_API_KEY` — тип Secret, ключ из шага 1;
   - `FIREBASE_PROJECT` = `raz-studio-5a486`;
   - `ALLOWED_ORIGIN` = `https://razgulyaevevgeny.github.io`.
4. **Запасной ИИ (по желанию).** Worker → Settings → Bindings → Add → Workers AI → имя `AI`. Когда дневной бесплатный лимит Gemini кончится, ответит запасная модель Cloudflare (тоже бесплатно, в пределах дневной нормы).
4а. **Instagram автоматически (по желанию).** Аккаунт студии — профессиональный (Бизнес или Автор). developers.facebook.com → создать приложение типа «Бизнес» → продукт Instagram → «Настройка API с бизнес-входом через Instagram» → «Сгенерировать токен» → в воркере секрет `IG_TOKEN`. Чтобы токен продлевался сам: Storage & Databases → KV → создать хранилище и привязать к воркеру с именем `IG_KV`.
5. **Адрес.** Если адрес воркера не `https://raz-marketing.design-onegin.workers.dev`, поменяйте `MKT_API` в начале `marketing.js`.
6. **Правила базы.** Firebase → Firestore Database → Rules: вставьте обновлённый `firestore.rules` (добавлен раздел `marketing`) → Publish. Без этого шага не сохранятся ни календарь, ни идеи.

Ограничения бесплатного варианта: у Gemini есть дневной лимит запросов (его видно в AI Studio), поиска в интернете нет — конкурентов вносите во вкладку «Конкуренты», аналитик работает с ними. Google может использовать запросы бесплатного тарифа для улучшения своих сервисов, поэтому имена и телефоны клиентов в ИИ не отправляются.

Если захочется умнее и с поиском в интернете — добавьте секрет `ANTHROPIC_API_KEY` (платно, console.anthropic.com), и отвечать будет Claude.
